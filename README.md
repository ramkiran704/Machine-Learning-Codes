# Machine Learning Algorithms 

This repository contains Jupyter Notebook implementations of important Machine Learning algorithms, including regression, classification, optimization, and statistical estimation techniques. It is designed to help me understand the mathematical concepts and practical implementation of Machine Learning using Python.

## Repository Contents

### 1. Gradient Descent
- `Gradient Descent.ipynb`
- `GradientDescent.ipynb`

Implementation and understanding of the Gradient Descent optimization algorithm used to minimize loss functions and optimize model parameters.

### 2. K-Nearest Neighbors (KNN)
- `KNN.ipynb`
- `KNN_Algorithm.ipynb`

Exploration of the K-Nearest Neighbors algorithm for classification and regression problems.

### 3. Linear Regression
- `LinearRegression.ipynb`
- `LinearRegression_Matrix.ipynb`
- `LinearRegression_Normal_eqn.ipynb`

Topics covered:
- Simple Linear Regression
- Matrix-based implementation
- Normal Equation method
- Model training and prediction

### 4. Maximum Likelihood Estimation and Maximum A Posteriori
- `MLE&MAP.ipynb`

Understanding Maximum Likelihood Estimation (MLE) and Maximum A Posteriori (MAP) methods for statistical parameter estimation.

### 5. Multinomial Naive Bayes and Bernoulli Naive Bayes
- `MNB&BNB.ipynb`

Implementation and study of Multinomial Naive Bayes and Bernoulli Naive Bayes classification algorithms.

### 6. Polynomial Regression
- `PolynomialRegression.ipynb`

Learning how polynomial features can model nonlinear relationships between input and output variables.

### 7. Regression Analysis
- `Regressions R&L.ipynb`

Exploration of regression concepts and techniques. 

### 8. Ridge and Lasso Regression
- `Ridge&Lasso.ipynb`

Understanding regularization techniques used to reduce overfitting:
- **Ridge Regression (L2 Regularization)**
- **Lasso Regression (L1 Regularization)**
